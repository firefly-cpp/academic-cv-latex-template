# icv – Academic CV LaTeX Class

**icv** is a lightweight LaTeX class for creating clean and structured academic CVs

The class focuses on readability, structured sections, and easy customization.

---

## Features

- clean academic CV layout
- structured sections for research CVs
- timeline-style entries for experience and education
- support for academic activities (reviewing, editorial roles, grants)
- simple commands for consistent formatting
- clickable links (DOI, websites, ORCID)
- easy to extend and customize

---

## Example Sections

The template supports common academic CV sections such as:

- Profile
- Academic Positions
- Education
- Research Interests
- Publications
- Edited Books and Proceedings
- Grants
- Invited Talks
- Editorial Activities
- Journal and Conference Reviewing
- Professional Service
- Teaching
- Supervision
- Open Source Contributions
- Outreach and Science Communication
